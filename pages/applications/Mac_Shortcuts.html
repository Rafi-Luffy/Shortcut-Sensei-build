Top Shortcuts for Mac

Master your Mac with essential keyboard shortcuts for macOS. Learn faster ways to manage apps, windows, and Finder. Capture screenshots, edit text, and navigate with confidence. Use these shortcuts daily to work faster and smarter.

Essential System & App Management

Shortcut Description
⌘ + Spacebar Open Spotlight search
⌘ + Tab Switch to the next most recently used app
⌘ + ` Switch between windows of the current app
⌘ + Q Quit the current application
⌥ + ⌘ + Esc Open the Force Quit Applications window
⌘ + H Hide the windows of the front app
⌥ + ⌘ + H Hide all other apps except for the front one
⌘ + M Minimize the front window to the Dock
⌥ + ⌘ + M Minimize all windows of the front app
⌘ + W Close the front window
⌥ + ⌘ + W Close all windows of the current app
⌘ + N Open a new window or document
⌃ + ⌘ + F Use the app in full screen
⌘ + , Open preferences for the front app
Spacebar Use Quick Look to preview the selected item
Fn + Q Create a Quick Note

Finder & File Management

Shortcut Description
⇧ + ⌘ + N Create a new folder
⌘ + D Duplicate the selected files
⌘ + Delete Move the selected item to the Trash
⇧ + ⌘ + Delete Empty the Trash (with confirmation)
⌥ + ⇧ + ⌘ + Delete Empty the Trash without confirmation
⌘ + I Show the Get Info window for a selected file
Return Rename the selected item
⌘ + ↓ Open the selected item
⌘ + ↑ Open the folder that contains the current folder
⇧ + ⌘ + G Open the "Go to Folder" window
⇧ + ⌘ + H Open the Home folder
⇧ + ⌘ + D Open the Desktop folder
⇧ + ⌘ + A Open the Applications folder
⇧ + ⌘ + O Open the Documents folder
⌥ + ⌘ + L Open the Downloads folder
⌘ + 1/2/3/4 Change the Finder view (Icon, List, Column, Gallery)
⌘ + K Open the Connect to Server window
⌥ + ⌘ + V Move files (cut and paste)

Screenshots & Screen Recording

Shortcut Description
⇧ + ⌘ + 3 Capture the entire screen
⇧ + ⌘ + 4 Capture a selected portion of the screen
⇧ + ⌘ + 4, then Spacebar Capture a specific window or menu
⇧ + ⌘ + 5 Open the Screenshot and screen recording options
⇧ + ⌘ + 6 Capture the Touch Bar
Add ⌃ to any screenshot shortcut Copy the screenshot to the clipboard instead of saving it

Document & Text Editing

Shortcut Description
⌘ + A Select all items
⌘ + C Copy the selected item
⌘ + V Paste the contents of the Clipboard
⌘ + X Cut the selected item
⌥ + ⇧ + ⌘ + V Paste text and match the destination formatting
⌘ + Z Undo the previous command
⇧ + ⌘ + Z Redo the previous command
⌘ + F Find items in a document
⌘ + S Save the current document
⌘ + P Print the current document
⌘ + B Bold the selected text
⌘ + I Italicize the selected text
⌘ + U Underline the selected text
⌃ + A Move to the beginning of a line or paragraph
⌃ + E Move to the end of a line or paragraph
⌘ + ← Move the cursor to the beginning of the current line
⌘ + → Move the cursor to the end of the current line
⌥ + ← Move the cursor to the beginning of the previous word
⌥ + → Move the cursor to the end of the next word
Add ⇧ to any cursor movement Select text while moving the cursor
Fn + Delete Forward delete (deletes characters to the right of the cursor)
⌃ + K Delete the text between the cursor and the end of the line
⌃ + ⌘ + Spacebar Show the Character Viewer to insert emojis and symbols
⌃ + ⌘ + D Look up a selected word's definition

Web Browser (Safari, Chrome, Firefox)

Shortcut Description
⌘ + T Open a new tab
⌘ + W Close the current tab
⇧ + ⌘ + T Reopen the last closed tab
⌃ + Tab Switch to the next tab
⌃ + ⇧ + Tab Switch to the previous tab
⌘ + L Highlight the URL/search bar
⌘ + R Reload the current page
⌘ + [ Go back to the previous page
⌘ + ] Go forward to the next page
⌘ + + Zoom in
⌘ + - Zoom out
⌘ + 0 Reset zoom to actual size
⇧ + ⌘ + N Open a new private browsing window

Sleep, Log Out & Shut Down

Shortcut Description
⌃ + ⌘ + Q Immediately lock your screen
⇧ + ⌘ + Q Log out of your user account (with confirmation)
⌥ + ⌘ + Power Button Put your Mac to sleep
⌃ + Power Button Show a dialog to restart, sleep, or shut down
⌃ + ⌘ + Power Button Force your Mac to restart

Accessibility

Shortcut Description
⌥ + ⌘ + F5 Show the Accessibility Shortcuts panel
⌘ + F5 Turn VoiceOver on or off
⌥ + ⌘ + 8 Turn Zoom on or off
⌥ + ⌘ + + Zoom in
⌥ + ⌘ + - Zoom out
⌃ + ⌥ + ⌘ + 8 Invert colors

Startup & Recovery

Shortcut Description
⌘ + R Start up from macOS Recovery
⌥ Start up to Startup Manager to select a startup disk
⇧ Start up in Safe Mode
D Start up to Apple Diagnostics
⌥ + ⌘ + P + R Reset NVRAM or PRAM
T Start up in Target Disk Mode
⌘ + V Start up in Verbose Mode
C Start from a bootable CD, DVD, or USB drive
